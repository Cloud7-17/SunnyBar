# 单次日程（0.3 预览）

双击可见时间条，打开统一编辑窗口；左侧“日程”“每日标记”是常用功能，下面“其他设置”提供地点、时间轴与外观、当前时间指针和运行选项。托盘“日程…”打开同一窗口的日程页，“标记与设置…”打开每日标记页。重复打开会复用窗口，切页保留当前草稿；关闭窗口放弃未保存的修改。

## 添加、编辑与删除

1. 点击“新建日程”，立即创建并保存一条“新日程”，同时选中它。默认从下一个半小时开始、持续一小时。
2. 选择可见色块，或点击“调色…”；备注可留空。结束时刻必须晚于开始时刻。
3. 在“编辑选中日程”区域填写标题、起止时间等，再点击“保存修改”，立即写入本地并更新时间条；修改保留原日程 ID。
4. 选择列表中的一行可编辑原日程，保存后保留同一 ID；点击“删除选中日程”立即删除并刷新。
5. “清除全部日程”在确认后立即删除所有过去、当前及未来日程并保存，不删除每日标记；“每日标记”页也有独立的“清除全部标记”。取消确认不修改数据，批量清除不可撤销。空列表或受保护文件下禁用按钮。

关闭窗口不退出应用；新建的默认日程已保存，没有点击“保存修改”的后续编辑不会写入。打开空列表或删除最后一项不会自动新建；无选中项时编辑区与保存按钮禁用。可创建过往或未来日程，当前最多 1000 条，标题最多 120 字符、备注最多 2000 字符。

## 时间轴显示

- 时间轴仍以本地 04:00 → 次日 04:00 为展示日，所有区间共用现有时间映射。
- 例如 14:00–16:00 写论文，会在对应位置叠加颜色区间；进行中的区间以白框突出。
- 03:00–05:00 跨过日界线时，两个展示日分别显示各自的一部分。多日事件也会裁剪到可见窗口。
- 相交日程分层排列，互不覆盖；相接但不重叠的区间可以复用同层。大量重叠时每层会变薄，标题与完整时间请查看日程列表。
- 色带默认只占时间条顶部 40%，下方保留昼夜底色；左侧“其他设置 → 时间轴与外观 → 日程高度占比”可调为 10%–100%，始终贴上沿。多个重叠层共用这部分高度。已保存的比例原样保留，可手动改为 40%。
- 每个真实起点用实心方形标志、终点用空心圆形标志强调；两端同色竖线从标志下方一直延伸到时间条最底部，与每日独立标记类似。只有覆盖色带受高度比例限制。跨日程被展示日边界裁剪的位置不冒充真实起止点。
- 进行中采用开始包含、结束不包含的规则；刚好结束即不再高亮。多个进行中日程可以同时显示。
- 日程窗口、预览与托盘提供当前/下一日程；下一项可以位于明天或更远日期。
- 悬停显示当前时间、下一每日标记及剩余时间，同时显示当前日程、开始/结束时间、距结束时间，以及下一日程和距开始时间。倒计时按真实时长计算并刷新；跨日显示日期，时刻附时区偏移。并行日程最多列出三项，其余提示在日程窗口查看。
- 可见色条接收点击以支持双击；单击不会打开编辑器或抢焦点，但会被色条接收。上方空白区域和悬停信息浮层继续穿透。不使用全局鼠标钩子。

## 时区和夏令时

使用日程窗口打开时显示的系统时区解释日期与时间，保存为带偏移的 DateTimeOffset。切换电脑时区后按新时区显示相同的真实时刻；如打开窗口时切换系统时区，请关闭并重新打开后编辑。

夏令时跳转中不存在的时刻会拒绝保存，要求选择其他时刻。新建时遇到重复小时默认第一次出现；编辑保留原来对应的偏移。只改标题、颜色或备注，不会丢失原时刻的秒或偏移。时间轴使用真实时间间隔，支持 23/25 小时展示日。

## 文件和恢复

日程单独保存在 `%LocalAppData%\SunnyBar\events.json`，不混入 settings.json。升级会保留原有地点、标记与外观；旧版不读取日程文件。

保存先写临时文件并落盘，再替换目标。损坏或不合法文件会先原样备份为 events.corrupt-*.json，再恢复空列表并提示路径；无法安全读取/备份或遇到更新版本格式时，保留原文件并禁止保存。当前格式的未知字段在编辑和保存时保留。

恢复文件前先退出托盘程序；可把可信备份复制为 events.json，再启动。没有自动监听外部文件修改，重新打开日程窗口会重新读取。

当前只做本地单次日程，没有重复规则、通知提醒、拖拽编辑、外部日历同步或云端账户。
