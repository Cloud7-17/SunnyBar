# 未来显示形态候选

来源：用户于 2026-10-27 对 M3 实际效果的反馈。以下仅作为后续设计方向，不代表本次实现或自动启动的开发任务。

- **极薄常态**：平时只保留一条很薄的日夜颜色带和最低限度指针。
- **任务栏/状态栏融合**：视觉上融入底部区域，以底色、不透明度等方式表达进度；具体系统兼容性后续评估。
- **悬停唤醒**：鼠标移近后再展开高度、图标或详细信息；移开后恢复低干扰形态。

后续需要明确唤醒区域、延迟、收起时机、点击穿透、全屏及自动隐藏任务栏的行为。继续优先采用独立悬浮窗口，任何系统任务栏内部改动均需单独评估。

本次仅完成全宽贴边、去除悬浮刻度和被动悬停信息提示。条的常态高度与不透明度不随悬停切换，没有实现自动隐藏、展开或修改系统任务栏底色。
