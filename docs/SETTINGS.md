# 设置、固定标记与恢复

首次运行会打开设置并默认采用北京预设；可在地点页切换上海、广州或手动经纬度，然后点击“保存并应用”。已有保存地点不会被重置，特罗姆瑟已移出预设。暂不选择也可使用中性色时间条。关闭设置后应用继续常驻；从托盘太阳图标重新打开。保存后立即更新，并在下次启动恢复。

## 可调整内容

- 地点：预设或手动坐标。按电脑系统时区解释，不自动定位或切换时区。
- 外观：宽度 20%–100%、色条高 6–24 DIP、底部间距 0–80 DIP、不透明度 0.2–1、日夜颜色及日出日落过渡半宽 5–120 分钟。默认全宽贴边，无小时刻度。
- 当前指针：圆点、星形、Emoji 或 PNG。Emoji 的颜色和字形取决于系统字体，当前 WPF 绘制可能呈单色。PNG 最多 5 MB，保存时复制到应用数据目录；原图移动不影响已保存副本，副本缺失或损坏时回退圆点并提示。
- 每日固定标记：添加、修改、删除、启停；填写标签；小时、分钟分别输入或下拉选择，保存时规范为 HH:mm；颜色可直接选择可见色块，或点击“调色…”打开调色盘。常用预设可一键添加：上班 10:00、午饭 12:00、晚饭 18:00、睡觉 23:00（不自动加入已有配置）。00:30 等早于 04:00 的标记放在展示日的次日。它们是每日时间点，没有日程起止区间。
- 运行：可选登录 Windows 后自动启动，默认关闭，仅对当前用户生效。取消勾选并保存可移除启动注册。

输入不合法时显示“未保存”，保留原配置和当前时间条。设置修改在保存后生效，详细预览显示已保存的当前状态。

## 本地文件

通过资源管理器地址栏打开 `%LocalAppData%\SunnyBar`：

| 文件 | 用途 |
|---|---|
| settings.json | 设置、地点、外观和每日固定标记 |
| Indicators/*.png | 导入的指针副本 |
| settings.corrupt-*.json | 损坏配置的原样备份 |
| settings.v0-*.json | 旧格式升级前的备份 |
| startup.cmd | 显式启用开机启动时生成的本地启动入口 |

保存先写入同目录临时文件并落盘，再替换 JSON。schemaVersion=0 会备份并升级；当前格式中的未知字段会保留。遇到更新版本格式，或无法安全读取/备份时，保留原文件、使用默认预览并禁止覆盖。修复问题或用匹配版本重新启动后可恢复编辑。

损坏配置会先原样备份，再恢复默认值并打开设置提示路径；不会静默丢弃原文件。需要手动恢复时，先退出托盘程序，再将可信备份复制为 settings.json，重新启动。不要在运行时直接编辑文件，应用不会监听外部文件修改。

## 开机启动说明

启用后写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中 SunnyBar 项。自包含便携版直接指向本地 EXE；开发版指向 startup.cmd。开发版启动入口会复用项目内 .NET 运行时，可能短暂闪过命令窗口。移动应用或运行时目录后需重新保存运行设置。没有勾选时不会自动开启。

当前已用替身验证保存与失败处理，没有替用户开启真实登录启动。实际注销/重新登录、多 DPI、休眠唤醒仍需实机验证。

## 建议自测

1. 双击 scripts/run.cmd，在托盘打开“设置…”。
2. 选择地点并保存，观察渐变；改宽度或不透明度，确认立即变化。
3. 添加 09:00 和 00:30 标记，保存，后者应在靠右约 85.42% 处（普通 24 小时日）。
4. 选择 PNG 并保存，移动原图，退出托盘再启动，确认指针和配置恢复。
5. 将时间误写成 25:00，保存应被拒绝；修正后再保存。
6. 鼠标停留在时间条约半秒，查看当前时间、下一标记与剩余时间；当天标记结束后自动查找明天，忽略已禁用标记，没有标记时显示“暂无”。日常点击应继续到达底下的窗口。

极薄常态、任务栏融合、悬停唤醒仍为未来候选，不在本阶段实现。下一阶段 M5 是发布与交付验证，尚不进入日程管理。
