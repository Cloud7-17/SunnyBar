# AI 日程导入格式 v1

在日程页点击“粘贴导入…”，粘贴纯 JSON，点击“校验并导入”，核对预览后确认追加。不执行文本里的命令，不连接 AI 或上传日程。

可以把下面这段要求交给 AI：

请按 Sunny Bar v1 格式生成纯 JSON，不要 Markdown 围栏或额外字段。根对象包含 version:1、timeZone（例如 Asia/Shanghai）和 events 数组。每项包含 title、date（yyyy-MM-dd）、start/end（HH:mm），可选 days、color（#RRGGBB）、notes。days 为每周重复的星期数字，周一=1 到周日=7；不重复请省略 days。date 是重复开始的最早日期；每天用 [1,2,3,4,5,6,7]，工作日用 [1,2,3,4,5]。所有计划先由我检查，不要遗漏日期或时区。

```json
{"version":1,"timeZone":"Asia/Shanghai","events":[
  {"title":"上课","date":"2026-11-02","start":"08:00","end":"09:35","days":[1,3,5]},
  {"title":"整理笔记","date":"2026-11-02","start":"20:00","end":"21:00"}
]}
```

结束时间早于开始时间表示次日结束。起止相同会拒绝，不隐式当作全天。省略颜色会自动配色。最多 1000 条（含已有规则），文本最多 1 MB；未知字段、错误时间、错误星期或无效时区会拒绝。导入是追加，同一文本再次导入会重复添加。

重复按规则保存的时区与当地时分计算，跨夏令时保持墙钟时间；不存在的时刻跳过当次，重复小时采用第一次。日期之前不展开，没有结束日期或节假日排除；工作日仅指周一到周五。编辑或删除一行作用于整个重复系列，暂不支持只改某一次。

包含重复规则的日程文件使用 schemaVersion=2，升级不改已有单次记录。请使用本版本或更新版本；旧版会将该文件视为未来格式并禁止覆盖。备份位于 %LocalAppData%\SunnyBar，升级前可先复制整个目录。
