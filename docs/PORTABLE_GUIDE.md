# Sunny Bar 便携版使用说明

版本：0.3.0-preview.1（预览版）
平台：Windows 11 x64；Windows 10 x64 尽力兼容，尚待实机验证。ARM64 未提供原生包。

## 启动

1. 将 ZIP 完整解压到普通可写目录，例如你的 Apps 文件夹下的 SunnyBar 子目录。
2. 双击 SunnyBar.App.exe。无需安装 .NET、SDK，不需要管理员权限或运行脚本。
3. 首次打开设置，默认北京。确认地点与电脑系统时区匹配后点击“保存并应用”。

请保留整个解压目录，不要只复制 EXE；程序旁边的 DLL 是附带的运行时。不要直接在 ZIP 内启动。

程序可能未在任务栏显示按钮，这是正常行为：它在系统托盘有太阳图标，可能收在隐藏图标区域。

## 日常操作

- 右键托盘太阳图标：显示/隐藏时间条、打开设置、退出。
- 双击托盘图标打开设置。关闭设置不会退出常驻程序。
- 鼠标停在时间条约半秒，仅显示当前时间、下一标记和倒计时；默认点击穿透。
- 每日固定标记可一键添加上班 10:00、午饭 12:00、晚饭 18:00、睡觉 23:00，也可分开选择小时/分钟和颜色。
- “运行”页可查看版本并选择登录 Windows 后自动启动，默认关闭。
- 时间轴以本地 04:00 到次日 04:00 为一天；00:30 等时刻位于时间轴靠右一侧。
- 日出日落为离线估算。选择异地城市不会切换电脑时区。

## 单次日程

托盘选择“日程…”或在设置点击“管理日程…”。填写标题、开始和结束日期与时间、颜色和备注，再点击“保存日程”。选择列表行可编辑或删除。时间轴显示颜色区间、重叠分层和当前高亮；详细规则见 SCHEDULES.md。

## 设置、升级与卸载

配置在 `%LocalAppData%\SunnyBar`，不在程序目录。相同 Windows 用户下，开发版与便携版共享配置和单实例锁；先退出旧版，再启动便携版。

升级：从托盘退出 → 将新包解压到新目录 → 启动新 EXE。地点、标记和 PNG 副本继续使用；如启用了开机启动，需重新保存此选项以更新路径。

卸载：在设置中取消开机启动并保存 → 从托盘退出 → 删除解压目录。配置保留，便于以后恢复；如需清空，可自行删除 `%LocalAppData%\SunnyBar`。若程序已被移走，可在 Windows“任务管理器 → 启动应用”中禁用 SunnyBar，再恢复程序取消注册；不要删除其他程序的启动项。

配置损坏时应用先备份原文件，再恢复默认设置并显示备份位置；新版本格式或无法备份时保留原文件并禁止覆盖。高级恢复见 SETTINGS.md。

## 当前限制与验证状态

本预览版只保证主屏、底部且非自动隐藏的任务栏。多屏选择、自动隐藏任务栏、全屏自动隐藏、极薄/融合/悬停展开、重复日程和外部日历同步未实现。

本机 Windows 已验证基础窗口定位、穿透样式、设置保存与重载；逻辑测试包括 23/25 小时 DST。实际 150%/200% 桌面缩放、休眠唤醒、注销登录启动、跨夜常驻和第二台无 .NET 的电脑仍需验证。不要将本机自包含启动检查等同于干净电脑验收。

该包未做代码签名，未配置安装器或自动更新。遇到系统拦截应先检查包来源与 SHA256；不要关闭系统安全保护。公开发布前需完成干净电脑验证。
