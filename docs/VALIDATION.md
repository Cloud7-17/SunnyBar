## 可复现入口

完整命令见 BUILD.md。仓库提供：

- tests/SunnyBar.Tests：纯逻辑单元测试。
- tools/SunnyBar.VisualChecks：使用独立数据目录的 WPF 绑定与渲染检查。
- scripts/publish.ps1：构建便携包、复制许可证并生成校验清单。
- scripts/verify-portable.ps1：校验完整目录、运行时声明和每个文件哈希。
- scripts/smoke-portable.ps1：使用无效外部运行时路径检查启动、窗口样式、单实例、退出和用户配置保留。

原始本机诊断和临时输出保留在被 Git 忽略的 artifacts 与 .tools 中，不纳入公开源码或 Release 附件。
