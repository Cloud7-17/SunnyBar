# 隐私说明

Sunny Bar 0.2.0-preview.1 在本机离线运行，没有账户、广告、遥测、自动更新或网络请求。日出日落由本地算法估算，不读取天气或联网定位。

- 地点为用户可修改的北京预设或手动坐标，不代表自动定位结果。
- 时间来自电脑时钟与系统时区。
- 地点、外观、每日标记和启动选项保存在 `%LocalAppData%\SunnyBar\settings.json`。
- 导入的 PNG 会复制到同目录的 Indicators 子目录；损坏配置备份也在该目录。
- 悬停只读取光标位置，以判断是否显示信息，不记录光标轨迹或按键，不读取其他程序内容。
- 仅在用户勾选并保存开机启动时，写入当前用户的 Windows Run 项；默认关闭。不创建系统服务，不要求管理员权限。
- 应用不主动上传上述内容。若操作系统、同步软件或用户将所在目录同步/备份到第三方，其行为由相应软件控制。

退出程序后可删除上述数据目录以清除设置、标记、导入图片与备份。卸载前应先取消开机启动并保存。详情见 PORTABLE_GUIDE.md。

源码构建时，NuGet 依赖恢复和 GitHub Actions 构建需要联网；它们属于开发流程，不是便携包运行行为。
